# Next.js frontend

Same public site as the Django templates, rendered by Next.js (App Router).
Django still owns `/admin/`, the database, uploads, `/media/`, `/static/`
and the JSON API under `/api/`.

## Local

```bash
# terminal 1, repo root
python manage.py runserver 127.0.0.1:8000

# terminal 2
cd frontend
bun install
bun run dev
```

`bun run dev` serves http://localhost:3000. `/static/*` and `/media/*` are
proxied to Django by `next.config.ts`, so images and PDFs need the Django
process running. `/api/contact/` is a small Next route handler that forwards
to Django (an `/api` rewrite loops because of `trailingSlash`).

`DJANGO_URL` overrides the backend origin (default `http://127.0.0.1:8000`).

## Production

```bash
bun install --frozen-lockfile
rm -rf .next/cache   # build-time API responses are cached; clear after content changes
bun run build
bun run start   # listens on 3000
```

The build fetches the Django API, so start Django before `bun run build`.
A campus page fails the build if the API is unreachable instead of baking a
404.

nginx serves Next on `/` and keeps these prefixes on gunicorn:

- `/admin/`
- `/api/`
- `/static/`
- `/media/`
- `/metrics/`
- `/health/`

`sitemap.xml` and `robots.txt` are generated by Next.

Content revalidates every 5 minutes (`lib/api.ts`), so uploads in the Django
admin appear without a rebuild.

## Layout

- `app/(site)/` — public pages (header/footer/main wrapper)
- `app/not-found.tsx` — standalone 404, matching the old error page
- `app/api/contact/` — forwards the contact form to Django
- `components/` — shell, header/footer, Embla carousel, map tabs, skeleton and
  `SmartImage` loading wrapper
- `css/` — the existing stylesheets plus `ui.css`. This directory is the single
  source: Django reads it through `STATICFILES_DIRS`.
- `lib/` — Django API client, types, nav links, metadata helper

Icons are Lucide React (tree-shaken SVGs). The carousel is Embla (swipe, arrows,
dots, no autoplay). Internal navigation uses `next/link`; `app/(site)/loading.tsx`
and `SmartImage` provide skeletons.

Bootstrap is not a dependency. `css/ui.css` implements only the grid,
utilities and component geometry this site uses; the navbar, dropdowns,
drawer and carousel are React state.

Links use plain `<a>` on purpose: the page scripts expect a full page load.
Converting to `next/link` would require reworking the carousel, lightbox and
filter initialisation first.
